# Support

Use GitHub Issues for reproducible package bugs and documentation defects. Include the package version, Angular version, browser, minimal configuration with secrets removed, expected behavior, actual behavior, and a minimal reproduction when possible.

The maintainers cannot provide UAE PASS tenant credentials, onboarding approval, production assessment, account recovery, or support for UAE PASS-operated services. Contact official UAE PASS channels for those requests.

Do not post client secrets, authorization codes, access tokens, refresh tokens, Emirates IDs, profiles, or other personal information. Report vulnerabilities privately according to `SECURITY.md`.
